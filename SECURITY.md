# Security

Found something that could break saves, write where it shouldn't or run code? Please don't open a public issue. Open the Security tab of [Sinerla-Development/Whiteout](https://github.com/Sinerla-Development/Whiteout) and choose Report a vulnerability.

Tell me the Whiteout version, your system and how to make it happen. I'll answer within a week, and fixes go into the latest release.
