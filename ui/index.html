Whiteout

Edit your Long Dark saves. Every save makes a backup first.

You can also drag a file into the window. It opens as a copy, and Save asks where to write it.

How it works
1
Watch your game while it runs. The open slot updates whenever the game saves. To get a fresh save, save in the game or change a video setting.
2
Edit only after closing the game, so it cannot overwrite your changes or keep an old version in memory.
3
Press Save to game. Whiteout makes a backup first. Then start the game and load the slot from the menu.

Arrow keys move the map. Plus and minus zoom, zero fits the map to the window.

      Usage

      • Choose a region from the list, grouped into Wintermute and Tales from the Far Territory. The map opens in your player's region when a slot is open, otherwise in the region you viewed last. Orange rings are transition points to neighboring regions.
      • Drag to pan, scroll or pinch to zoom. Keyboard: arrows pan, plus and minus zoom, 0 fits the map to the window.
      • Search finds regions, places and your own pins. Places were read from the images with text recognition, so the list is not complete.
      • Use the Pin tool to add your own pins. They are kept in your data folder.
      • When a slot is open, your position shows as a green dot in 13 regions, and the Teleport tool sets the teleport to the spot you click. The position updates when the game saves, and Follow player switches the map along with your region. In an area without a map, the current map stays open.
